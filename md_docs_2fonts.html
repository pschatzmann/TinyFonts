Available fonts

The fonts below are generated with tools/tinyfonts_convert.py and ship with the library in src/TinyFonts/Fonts/. Include them with #include <TinyFonts/Fonts/Lato16.h>. To include all of them, use #include <TinyFonts/Fonts/Fonts.h>. Unused fonts add nothing to the compiled sketch. Each font is one header file that defines a tinyfonts::Font object with the same name as the file. All use 2 bits per pixel.

Licences

  • Lato is licensed under the SIL Open Font License 1.1.
  • Arial entries are generated from Liberation Sans, which is metric-compatible with Arial and licensed under the SIL Open Font License 1.1. They are not Microsoft's Arial.
  • Helvetica entries are generated from Nimbus Sans (URW base35), an open Helvetica-compatible font. Check its licence terms, which include a font exception, before you ship the generated data. They are not Linotype's Helvetica.

Check the licence of any font you convert before you ship the output.
