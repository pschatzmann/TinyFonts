TinyFonts

Header-only font rendering for Arduino and plain C++. Fonts are converted on your development machine into compact byte arrays. The device-side renderer needs no heap and no display library.

Features

  • Anti-aliasing at 1, 2, 4 or 8 bits per pixel
  • Kerning, proportional advances, word wrap and UTF-8 text
  • Fonts in flash (PROGMEM) or RAM
  • 13 ready-to-use fonts in src/TinyFonts/Fonts/ (Lato, Arial- and Helvetica-compatible)
  • Draws through a small FontDisplay interface, so any display library works
  • Optional integration with TinyGPU

Installation

Arduino

Download the library as a zip and use Sketch → Include Library → Add .ZIP Library. Or clone the project into your Arduino libraries folder:

cd ~/Documents/Arduino/libraries
git clone https://github.com/pschatzmann/TinyFonts.git

Using git makes updates easy: run git pull in the project folder. The font converter is a Python tool; see Font converter for its requirements.
