Header-\/only font rendering for Arduino and plain C++. Fonts are converted on your development machine into compact byte arrays. The device-\/side renderer needs no heap and no display library.\hypertarget{md_README_autotoc_md1}{}\doxysection{\texorpdfstring{Features}{Features}}\label{md_README_autotoc_md1}

\begin{DoxyItemize}
\item Anti-\/aliasing at 1, 2, 4 or 8 bits per pixel
\item Kerning, proportional advances, word wrap and UTF-\/8 text
\item Fonts in flash (PROGMEM) or RAM
\item 13 ready-\/to-\/use fonts in {\ttfamily src/\+Tiny\+Fonts/\+Fonts/} (Lato, Arial-\/ and Helvetica-\/compatible)
\item Draws through a small {\ttfamily Font\+Display} interface, so any display library works
\item Optional integration with \href{https://github.com/pschatzmann/TinyGPU}{\texttt{ Tiny\+GPU}}
\end{DoxyItemize}\hypertarget{md_README_autotoc_md2}{}\doxysection{\texorpdfstring{Installation}{Installation}}\label{md_README_autotoc_md2}
\hypertarget{md_README_autotoc_md3}{}\doxysubsection{\texorpdfstring{Arduino}{Arduino}}\label{md_README_autotoc_md3}
Download the library as a zip and use {\bfseries{Sketch → Include Library → Add .ZIP Library}}. Or clone the project into your Arduino libraries folder\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{cd\ \string~/Documents/Arduino/libraries}
\DoxyCodeLine{git\ clone\ https://github.com/pschatzmann/TinyFonts.git}

\end{DoxyCode}


Using git makes updates easy\+: run {\ttfamily git pull} in the project folder.
