Getting started

This page shows the runtime API. To create the font data, see converter.md.

Basic drawing

TinyFonts renders into any target that implements tinyfonts::FontDisplay. The target receives one call per pixel with a coverage value from 0 (no ink) to 255 (full ink) and blends it with the background itself.

#include <TinyFonts.h>
#include <TinyFonts/Fonts/Lato12.h> // bundled, or generated by tools/tinyfonts_convert.py
class MyDisplay : public tinyfonts::FontDisplay {
public:
void drawPixel(int x, int y, uint8_t coverage) override {
// blend `coverage` with the background and write the pixel
}
};
MyDisplay display;
tinyfonts::TextRenderer text(Lato12, display);
text.drawText(0, 0, "Hello, TinyFonts!"); // \n starts a new line
text.drawText(0, 40, "A longer paragraph ...", 120); // wrapped to 120 px

drawText(x, y, text, maxWidth) puts the top-left corner of the first line at (x, y). The baseline sits ascent pixels below it. maxWidth <= 0 disables wrapping. The function returns a tinyfonts::TextBox with the drawn width, height and line count.

Lower-level helpers

  • tinyfonts::decodeUtf8(p, end) decodes one UTF-8 character and advances p.
  • tinyfonts::wrapText(font, begin, end, maxWidth, onLine) calls onLine for each wrapped line.
  • tinyfonts::findGlyph, tinyfonts::kerning and tinyfonts::Font expose the font data directly. See format.md.

Fonts in flash

Generated fonts are PROGMEM arrays with a tinyfonts::Font object. On AVR and ESP8266 the library reads them from flash automatically. On other boards they are ordinary constant data.

Features and limits

  • Coverage depth of 1, 2, 4 or 8 bits per pixel (anti-aliasing).
  • Proportional advances, pair kerning from the kern and GPOS tables.
  • Ascent, descent and line gap; \n line breaks.
  • Word wrapping. Words that are too long are split between characters.
  • UTF-8 input. Characters the font lacks are drawn with the fallback glyph.
  • Clipping rectangle.
  • Not implemented yet: TrueType/CFF outline rendering, signed distance fields, colour glyphs, complex text shaping (ligatures, Indic scripts) and font fallback chains.
