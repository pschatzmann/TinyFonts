Detailed Description

template<typename RGB_T = tinygpu::RGB565>
class tinyfonts::TinyGPUDisplay< RGB_T >

FontDisplay that writes TinyFonts coverage into a TinyGPU surface.

Each pixel is alpha-blended over the background. Used internally by TinyGPUFont.
